# CFD Aerodynamics & Fluid Dynamics (ANSYS Fluent)

Computational Fluid Dynamics (CFD) projects and lab practices developed at **UNAQ**.

## Overview
This repository groups aerodynamics and fluid mechanics simulations performed with **ANSYS Fluent**, **Python / Jupyter**, and **SolidWorks** geometries.

## Contents
- **`proyecto/`** — Aerodynamic simulation of a drone semi-wing using the **Selig S1223** high-lift airfoil (`Perfil S1223.txt`, `Semiala Derecha (Referencia) 3.STEP`, ANSYS Workbench `.wbpj` setups).
- **`Pitot_tube.ipynb`** — Jupyter Notebook for Pitot tube flow analysis and post-processing.
- **`practica 3/` – `practica 7/`** — Progressive CFD lab practices covering meshing, boundary conditions, and flow visualization.

## Tools & Technologies
- **ANSYS Fluent & ANSYS Workbench**
- **Python / Jupyter Notebook**
- **CAD:** `.STEP` geometry definitions

> *Note: Heavy solver mesh and data binaries (`.msh`, `.cas.h5`, `.dat.h5`) are excluded via `.gitignore`.*
